实时数仓管理系统 — RESTful API 设计

Spring Boot 3.x · Flink 2.x + Paimon · Ant Design Pro v6

Base URL: http://{host}:8080/api/v1  |  认证方式: Bearer JWT  |  响应格式: application/json

1. 认证与权限 Auth & RBAC

POST /auth/login 用户登录，获取 JWT Token
参数类型必填说明
usernameString必填用户名
passwordString必填密码

200 OK

{ "token": "eyJhbG...", "expiresIn": 86400, "user": { "id": 1, "username": "admin", "realName": "管理员", "roles": ["ADMIN"] } }
POST /auth/logout 用户登出

200 OK

{ "message": "Logged out successfully" }
GET /auth/current-user 获取当前登录用户信息及权限

200 OK

{ "id": 1, "username": "admin", "roles": ["ADMIN"], "permissions": ["task:create", "task:delete", "query:adhoc", ...] }
GET /users 用户列表（分页）
参数类型必填说明
pageInteger可选页码，默认 1
sizeInteger可选每页数量，默认 20
keywordString可选搜索关键词
POST /users 创建用户
PUT /users/{id} 更新用户信息
DELETE /users/{id} 删除用户（软删除）

2. 数据源配置 Datasource

GET /datasources 数据源配置列表
参数类型必填说明
dbTypeString可选按类型筛选：mysql / postgresql / paimon
POST /datasources 创建数据源配置
参数类型必填说明
configNameString必填配置名称
dbTypeString必填数据库类型
hostString必填主机地址
portInteger必填端口
databaseString必填库名
usernameString必填用户名
passwordString必填密码（传输后加密存储）
extraParamsObject可选额外参数 JSON
GET /datasources/{id}/test-connection 测试数据源连接是否可用

200 OK

{ "success": true, "message": "Connection established", "dbVersion": "MySQL 5.7.38" }
GET /datasources/{id}/tables 获取数据源下的表列表（用于任务配置映射）

3. 同步任务管理 Sync Task — 核心

GET /sync-tasks 同步任务列表（分页+筛选）
参数类型必填说明
pageInteger可选页码
sizeInteger可选每页数量
statusString可选按状态筛选：draft/running/paused/failed/finished
taskTypeString可选按类型筛选
keywordString可选名称搜索
POST /sync-tasks 创建同步任务
参数类型必填说明
taskNameString必填任务名称
taskTypeString必填任务类型：cdc_sync / etl / materialized
scenarioCodeString必填产品场景编码
executionModeString必填continuous / scheduled
sourceConfigIdLong条件必填CDC 业务源数据源配置 ID
targetConfigIdLong兼容字段已废弃；目标统一使用系统设置中的 Paimon Catalog
flinkSqlString必填Flink SQL 语句（CDC → Paimon 的完整定义）
syncStrategyString必填同步策略
tableMappingsObject可选表映射配置 JSON

200 OK

{ "id": 101, "taskName": "mysql_orders_cdc", "status": "draft", "createdAt": "2026-06-26T10:00:00" }
PUT /sync-tasks/{id} 更新任务配置（仅 draft 状态可编辑）
POST /sync-tasks/{id}/start 启动任务（提交至 Flink 集群）

200 OK

{ "status": "running", "flinkJobId": "a1b2c3d4e5f6", "message": "Task submitted to Flink cluster" }
POST /sync-tasks/{id}/pause 暂停任务（触发 Flink stop-with-savepoint）
POST /sync-tasks/{id}/resume 恢复任务（从 savepoint 恢复提交）
POST /sync-tasks/{id}/stop 停止任务（cancel Flink job）
DELETE /sync-tasks/{id} 删除任务（仅 draft/finished 状态可删）
GET /sync-tasks/{id}/status 获取任务实时状态（含 Lag、QPS、Checkpoint）

200 OK

{ "status": "running", "flinkJobId": "a1b2c3d4e5f6", "currentLagMs": 1520, "throughputQps": 2350.5, "checkpointInfo": { "latestCheckpointId": 4826, "latestCheckpointTime": "2026-06-26T16:30:00", "checkpointIntervalMs": 30000, "stateSizeBytes": 52428800 }, "lastErrorMsg": null }
GET /sync-tasks/{id}/logs 获取任务日志（TaskManager / JobManager）
参数类型必填说明
typeString可选jobmanager / taskmanager
taskIdString可选Flink subtask ID
linesInteger可选返回行数，默认 200

参数类型必填说明
layerString可选按分层筛选：ods/dwd/dws/ads
databaseString可选按库名筛选
keywordString可选表名搜索
GET /dwh/tables/{id} 获取表详情（结构、分区、快照、文件统计）

200 OK

PUT /dwh/tables/{id}/metadata 更新表业务描述 / 字段注释
GET /dwh/lineage 获取数据血缘关系图
参数类型必填说明

layerString可选按分层查看

5. 表维护操作 Maintenance

POST /dwh/tables/{id}/compact 手动触发 Compact 优化
参数类型必填说明
compactStrategyString可选full / minor，默认 minor

200 OK

{ "operationId": 201, "status": "running", "message": "Compact triggered" }
POST /dwh/tables/{id}/expire-snapshots 手动触发快照过期清理
参数类型必填说明
retainLastInteger必填保留最近 N 个快照
retainMaxAgeString可选最大保留时长如 "7d"
POST /dwh/tables/{id}/orphan-cleanup 清理孤立文件
GET /dwh/tables/{id}/maintenance-logs 获取表维护操作日志列表

7. 即席查询 Ad-hoc Query

POST /query/execute 执行 SQL 查询（通过 Flink SQL Gateway 或 JDBC）
参数类型必填说明
sqlString必填SQL 语句
maxRowsInteger可选最大返回行数，默认 1000，上限 5000
timeoutSecondsInteger可选超时时间，默认 60s

200 OK

{ "columns": ["order_id", "user_id", "amount"], "rows": [[1, 101, 99.9], [2, 102, 150.0]], "rowCount": 2, "durationMs": 320 }
POST /query/execute/export 执行查询并导出结果为 CSV/Excel
参数类型必填说明
sqlString必填SQL 语句
formatString必填导出格式：csv / xlsx
maxRowsInteger可选最大行数，上限 50000
GET /query/history 查询历史记录

8. 报表管理 Report

GET /reports 报表模板列表
POST /reports 创建报表模板
参数类型必填说明
reportNameString必填报表名称
reportTypeString必填图表类型：line/bar/pie/table/mixed
sqlQueryString必填SQL 查询语句
chartConfigObject可选ECharts 配置 JSON
filterConfigObject可选筛选条件配置
scheduleConfigObject可选定时发送配置
GET /reports/{id}/data 获取报表数据（按筛选条件执行 SQL）
POST /reports/{id}/send 手动发送报表（邮件/IM）

9. 告警管理 Alert

GET /alerts/configs 告警配置列表
POST /alerts/configs 创建告警配置
GET /alerts/records 告警记录列表
POST /alerts/records/{id}/resolve 标记告警已解决
