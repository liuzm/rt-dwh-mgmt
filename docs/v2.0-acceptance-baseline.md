## 性能记录与后续目标

API 升级前后均为同机、顺序 20 次、并发 1、单行常量查询，包含应用凭证校验与真实 Doris 查询。升级前中位数 75.49ms、P95 80.17ms；升级后中位数 80.30ms、P95 86.12ms。观测 P95 增加约 7.4%，样本和数据量不足以得出容量结论。

升级前健康接口 P95 3.50ms，前端 HTML P95 0.84ms。这些是空闲响应，不能代表页面可交互耗时、带权限的列表检索、大表扫描或质量检测成本。
